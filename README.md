# 🛡️ AegisGuard AI: Automated Phishing & Deepfake Defense System

> An enterprise-grade, AI-powered threat intelligence platform designed to detect sophisticated phishing emails, malicious URLs, and synthetic media in real time.

---

## 🚀 Key Features
- **Real-Time Phishing Detection:** NLP and heuristic-based scanning engine to analyze incoming email headers, bodies, and sender domains for spoofing.
- **Deepfake Media Analysis:** Automated inspection framework to flag synthetic audio/video manipulations and facial landmark anomalies.
- **Automated Threat Scoring:** Risk-scoring system ranging from 0.0 (Safe) to 1.0 (Critical Threat) with instant SOC recommendations.
- **Interactive Dashboard:** Modern React + Tailwind CSS web interface for security operations teams.

---

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI, Uvicorn, Pydantic
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Architecture:** RESTful APIs with CORS enabled, modular backend structure
